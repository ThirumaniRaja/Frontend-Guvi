REDUX... 

REDUX is the global state management library.. it stores the data that needs to be shared across muliple components


RTK (Redux Toolkit),, recommended way to write the redux 


Redux: State management library that stores shared application state in a single store and updates it using the actions and reducers 

Redux Store: Centralized object that holds application state

State: Data used by the application

Action: JS object describing what action happened 

Reducer: is a function that returns a new state based on the current state and action 

Dispatch: function that sends an action to the redux store
